Mosaics & mixed scopes · experimental mono Hα

Choose your exposures and a new result folder. Smokstak finds the panels, aligns stars across scopes and matches shared sky. You review the layout before building. Original frames remain untouched.

1  Choose frames and where to save

Includes subfolders. First pass: 2–512 uncompressed 16-bit mono Hα FITS exposures. Panels need overlapping stars; filenames and panel numbers are not required.

Other ways to choose frames

Select frames using any one of the methods above.

The preparation and reusable star cache are saved beside the result folder. Existing results are never overwritten.

Automatic preparation checks every selected frame. If overlaps or alignment are unreliable, it stops and explains the problem.

Optional: reuse a prepared plan

Skip preparation when you already have a checked plan. Changing the frame selection requires preparing again.

Optional: memory and tile settings

Smaller tiles reduce memory use. The budget limits estimated image buffers, not total operating-system memory. Output scale is fixed by the plan.

2  Review the detected layout

The layout appears when preparation finishes. Check the canvas and source count; inspecting individual frames is optional.

Group filters change this review only. Every exposure in the plan is still included in the build. Unlabelled plans list their sources individually.

Dashed outline: output canvas. Click a footprint or choose a source to see its registration measurements. Coordinates are relative; this is not an absolute sky map.

Preparation notes

Review checks geometry and source availability. The build verifies source fingerprints and filters again. Different-resolution data retain the finest available group; broader data contribute outside it. Raw gradients and incomplete faint-track rejection can remain.

Optional: measure and exclude frames
      
The stack already weights every frame by how sharp it is,
        so a soft frame costs little. A frame that is wrong rather than soft — stars trailed by wind
        or a snag, a sky thinned by cloud — is worth leaving out, and finding one means measuring
        every frame once. That takes about as long as decoding them, and the settings below can be
        chosen while it runs.

Optional: noise and integration analysis · mono
      
Measure how random noise changes as frames accumulate, inspect trends and export questionable-frame lists. This analyzes the loaded input set minus your survey exclusions. It does not measure a finished master or automatically discard frames. The analysis uses all remaining frames, regardless of the trial stack limit.

      
      
Each analysis creates a new report folder. Compact measurement caches are reused. Large datasets can take considerable time.
