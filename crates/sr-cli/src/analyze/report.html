How to read these measurements

Split noise estimates random noise by differencing balanced halves of the integration. Stable astronomical structure and shared errors cancel; seeing and alignment differences can remain. Odd frame counts have no balanced measurement. This is a sampled analysis, not a measurement of a finished, rejection-weighted master.

The gold guide starts at the first balanced measurement and assumes equally noisy, independent frames. It is a reference, not a fit or a prediction. A rising measured curve is a reason to inspect the data, not an instruction to discard a night.

What this SNR means

Contrast SNR = (signal-patch median − background-patch median) / √(signal split-noise² + background split-noise²). This is a per-sample contrast proxy including noise in both regions, not aperture SNR or detection significance. It omits shared systematic errors and spatial covariance. Goals refer only to this definition. Previews share the same physical stretch so a change in display stretch cannot masquerade as improvement.

Each upward step identifies the newly added pair (or interval) between balanced measurements. It does not prove which frame caused the increase. Compare both originals for clouds, broad or elongated stars, artifacts and calibration problems before excluding either.

The bundle contains a retained-frame list for another run, a separate questionable-frame list, a CSV/JSON evidence manifest, and a PowerShell helper to copy the original files into a new inspection folder. It covers all filters in this report and removes only frames you mark. Source images are not embedded in the report; the copy helper needs access to the original drives.

Selections are provisional and reset on reload; save the bundle to retain them. Removing frames changes split pairing and may change the reference/common footprint. Rerun with the same settings and compare the final result, not only this noise curve. The list reader uses normal filename order.
